# Frontend-Backend Connection Setup

This guide explains how to configure the frontend (Vercel) to connect with the backend (Render).

## Architecture Overview

```
User Browser
    ↓
Vercel Frontend (React/Vite)
    ↓ (API Requests with JWT Token)
Render Backend (Django/DRF)
    ↓
SQLite Database
```

## Step-by-Step Setup

### Step 1: Deploy Backend on Render

1. Go to **[render.com](https://render.com)**
2. Click **New** → **Web Service**
3. Connect your GitHub repo: `Athullvr/Subscription-Manager`
4. Configure:
   - **Name**: `subscription-manager-api`
   - **Root Directory**: `backend`
   - **Build Command**: (Use default from render.yaml)
   - **Start Command**: (Use default from render.yaml)

5. **Environment Variables** - Render should auto-load from `render.yaml`:
   - `DEBUG`: `false`
   - `SECRET_KEY`: Auto-generated by Render
   - `ALLOWED_HOSTS`: `subscription-manager-api.onrender.com,localhost,127.0.0.1`
   - `CORS_ALLOWED_ORIGINS`: `https://subscription-manager.vercel.app,http://localhost:5173,http://localhost:3000`
   - `PYTHON_VERSION`: `3.12`

6. Click **Create Web Service** and wait for deployment (2-3 minutes)

7. **Note the deployed URL**: Copy the URL from the dashboard, it should be like:
   ```
   https://subscription-manager-api.onrender.com
   ```

### Step 2: Deploy Frontend on Vercel

1. Go to **[vercel.com](https://vercel.com)**
2. Click **Add New** → **Project**
3. Import: `Athullvr/Subscription-Manager`
4. Configure:
   - **Framework**: Vite
   - **Root Directory**: `frontend`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`

5. **Environment Variables** - Add this IMPORTANT variable:
   - **Name**: `VITE_API_BASE_URL`
   - **Value**: `https://subscription-manager-api.onrender.com/api`
   
   (Replace `subscription-manager-api` with your actual Render service name if different)

6. Click **Deploy** and wait (1-2 minutes)

7. **Test the deployment** by visiting your Vercel URL

### Step 3: Verify the Connection

#### Test Registration & Login
1. Open your Vercel frontend URL
2. Click **Register** and create a test account
3. Submit the form - it should:
   - Make a POST request to your Render backend
   - Redirect to login page on success
4. Log in with your credentials
5. If successful, you'll see the dashboard

#### Test Subscription Creation
1. Click **Add Subscription**
2. Fill in:
   - Service Name: `Netflix`
   - Monthly Cost: `15.99`
   - Billing Date: `15`
   - Category: `Streaming`
3. Click **Add Subscription**
4. Verify it appears on the dashboard

#### Verify API Calls in Browser Console
1. Open Developer Tools (F12)
2. Go to **Network** tab
3. Perform any action (login, add subscription, etc.)
4. You should see requests to `https://subscription-manager-api.onrender.com/api/...`
5. Check response status (should be 2xx for success)

### Step 4: Update Backend CORS (if needed)

If you're getting CORS errors after deployment:

1. Go to Render dashboard → Your API service
2. Click **Environment**
3. Edit `CORS_ALLOWED_ORIGINS` to include your Vercel URL:
   ```
   https://subscription-manager.vercel.app,http://localhost:5173,http://localhost:3000
   ```
4. Click **Save** and the service will redeploy

## Troubleshooting

### Error: "Failed to fetch subscriptions"

**Issue**: Frontend can't connect to backend

**Solutions**:
1. Check `VITE_API_BASE_URL` env var on Vercel is correct
2. Verify Render backend is running (check Render logs)
3. Check browser console for exact error message
4. Try the API directly:
   ```bash
   curl -X GET https://subscription-manager-api.onrender.com/api/subscriptions/ \
     -H "Authorization: Bearer <YOUR_TOKEN>"
   ```

### Error: "CORS error" or "No 'Access-Control-Allow-Origin' header"

**Issue**: Backend isn't allowing requests from frontend

**Solution**:
1. Go to Render dashboard
2. Check `CORS_ALLOWED_ORIGINS` includes your Vercel URL
3. Update if needed and save (triggers redeploy)
4. Wait 2-3 minutes for redeploy to complete

### Error: 401 Unauthorized

**Issue**: JWT token issue

**Solution**:
1. Try logging out (clears localStorage)
2. Register a new account
3. If still failing, check Render logs for authentication errors

### Error: 404 on routes like `/login`, `/register`

**Issue**: Frontend routing not working on Vercel

**Solution**:
- Vercel automatically handles SPA routing for Vite
- This should work out of the box
- Check Vercel deployment logs if persisting

## Important Notes

1. **Cold Start**: Render's free tier may sleep after 15 minutes of inactivity. The first request after sleep can take 30-60 seconds. This is normal.

2. **Database**: SQLite is reset on Render redeploys. To persist data, upgrade to PostgreSQL.

3. **Secrets**: Never commit `.env` files to Git. Use Vercel and Render's environment variable interfaces.

4. **CORS**: Both frontend and backend URLs must be added to `CORS_ALLOWED_ORIGINS` for requests to work.

5. **JWT Tokens**: 
   - Access Token: 1 hour expiry
   - Refresh Token: 1 day expiry
   - Auto-refresh happens transparently on 401 response
